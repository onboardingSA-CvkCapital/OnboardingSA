About the role

We are looking for an Senior Cryptography Engineer to design, implement and integrate secure cryptographic solutions for payment and financial systems. The ideal candidate combines applied cryptography, backend software engineering, HSMs and payment security, with the ability to translate technical standards into reliable production systems. Key Responsibilities ● Design and implement cryptographic services and backend components. ● Integrate applications with enterprise HSMs and cryptographic infrastructure. ● Implement key-management and key-lifecycle processes. ● Work with payment cryptography, including PIN blocks, DUKPT, CVV/CVC, PVV and EMV. ● Implement and troubleshoot protocols and standards such as TR-31 and TR-34. ● Investigate cryptographic and security incidents. ● Perform security-focused code reviews and testing. ● Work with clients and partners on technical integrations. ● Participate in architecture, security and technical design discussions. ● Research emerging cryptographic and security technologies. ● Produce technical documentation for cryptographic systems and integrations. Cryptography & Security ● Strong understanding of symmetric and asymmetric cryptography. ● AES, RSA, ECC, hashing, HMAC and key derivation. ● Cryptographic key management and lifecycle. ● Secure random number generation and key material handling. ● PKI, TLS and authentication. ● Threat modelling and secure software development. ● Understanding of common cryptographic implementation vulnerabilities. Payment Cryptography ● TR-31 and TR-34. ● Payment HSMs. ● PIN blocks, DUKPT, CVV/CVC and PVV. ● EMV cryptography. ● Payment key hierarchies and key ceremonies. ● Thales payShield experience is highly advantageous. Software Engineering ● Strong proficiency in at least one backend language: TypeScript/JavaScript, Java, Go, C/C++ or Python. ● Production backend development. ● REST APIs and service-to-service communication. ● Linux, Git and modern software-development practices. ● Automated testing. ● Networking fundamentals and distributed systems. ● Observability, logging, metrics and tracing. DevOps & Infrastructure — Optional ● Kubernetes and Docker/containerisation. ● CI/CD and Infrastructure as Code. ● Cloud platforms and Linux administration. ● Monitoring and observability. ● Secrets management and infrastructure security. ● DevOps and Kubernetes experience is not a core requirement, but is a strong advantage. Standards & Industry Knowledge ● PCI PIN / PCI PTS and PCI DSS. ● ISO 9564, ISO 8583 and ISO 20022. ● ANSI X9, EMV and PKCS standards. Client & Integration Skills ● Work directly with technical client teams. ● Analyse integration requirements and troubleshoot production integrations. ● Explain complex cryptographic concepts clearly. ● Participate in technical implementation sessions. ● Travel to client sites when required. Research & Development ● Trusted Execution Environments (TEEs). ● Passkeys/WebAuthn. ● Zero-Knowledge Proofs. ● Fully Homomorphic Encryption. ● Confidential Computing. ● Post-Quantum Cryptography. ● Hardware-backed security. ● The ability to independently learn complex technical concepts and apply them practically is more important than knowing every technology listed. Minimum Requirements ● Bachelor's degree in Computer Science, Computer Engineering, Electrical Engineering, Mathematics, Cybersecurity or a related field. ● 5 years of relevant professional experience. ● Production software-development experience. ● Strong foundations in computer science, cryptography and security. ● Ability to work independently on technically complex problems. Preferred Experience ● Payment or fintech experience. ● HSM experience and Thales payShield. ● TR-31/TR-34 implementation or integration. ● PKI and certificate infrastructure. ● Cloud security. ● Security research/R&D.; ● Client-facing technical integrations. ● Kubernetes/DevOps. Ideal Candidate ● The ideal candidate is an applied cryptographer who can also engineer production systems. ● They should be able to take a cryptographic requirement, understand the underlying security model and standard, determine the required keys and cryptographic operations, integrate with the HSM, implement the backend components, test the solution and troubleshoot it in production. Core Skill Profile Cryptography + HSMs + Payment Security + Backend Engineering + Security Engineering Kubernetes, DevOps and cloud infrastructure are valuable additional skills but are not prerequisites for the role. • Very good development experience and capabilities.
