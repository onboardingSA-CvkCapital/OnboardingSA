About the role

FirstRand is hiring a Murex Engineer (Testing and Automation), based in Johannesburg. The Junior Murex Engineer - Testing and Automation is responsible for supporting the quality, reliability and repeatability of Murex MX.3 testing through automated test execution, MxTest test pack maintenance, scripting, test data preparation and operational automation. The role is focused on reducing manual testing and operational effort by building and maintaining reusable automated test scripts, supporting regression test packs, automating repeatable checks using Python and Bash scripting, and assisting with test execution across Murex changes, releases, projects, upgrades and production support activities. The role requires a strong technical mindset, willingness to learn the Murex platform, practical scripting ability, attention to detail and the ability to work closely with Murex engineers, business analysts, developers, testers, support teams and business users. This is a hands-on junior engineering role. The successful candidate is not expected to be a senior Murex specialist from day one, but should be able to grow into a strong Murex testing and automation engineer through structured exposure to MX.3, MxTest, test automation practices and Murex operational processes. This role is primarily a Murex testing and automation engineering role, not a general manual testing role and not a senior Murex functional specialist role. The primary focus is to support Murex quality engineering by automating test scenarios using MxTest, maintaining reusable regression packs, executing automated tests, analysing test results, preparing test data, scripting repeatable operational checks, and using Python and Bash to reduce manual processing across Murex testing and support activities.

Responsibilities

  • Murex Testing and Test Execution
  • Support testing activities for Murex MX.3 changes, enhancements, releases, upgrades and regression cycles.
  • Execute MxTest automated test cases and record test outcomes accurately.
  • Assist with manual test execution where automation is not yet available.
  • Support the preparation of test cases, test data, test environments and test tools before execution.
  • Log, track and communicate test results, defects, failed test cases and execution issues.
  • Perform first-level analysis of failed tests before escalating to senior engineers, developers or support teams.
  • Support system integration testing, regression testing, user acceptance testing and production validation activities.
  • MxTest Automation
  • Build, maintain and execute automated test scripts using MxTest.
  • Assist in the creation and maintenance of reusable automated regression test packs.
  • Automate repeatable Murex test scenarios based on agreed testing standards and automation practices.
  • Support automated testing across relevant Murex processes, workflows, interfaces, reports and operational flows.
  • Maintain test automation artefacts so that they remain reusable, understandable and supportable.
  • Help improve test coverage by identifying manual test cases that can be automated.
  • Assist with test execution summaries, automation reporting and evidence collection.
  • Python, Bash and Operational Automation
  • Use Python and Bash scripting to automate repetitive testing, validation, reconciliation and operational support tasks.
  • Develop scripts to reduce manual effort in test data preparation, file checks, log checks, result comparisons and routine validations.
  • Support automation of recurring operational checks where appropriate.
  • Assist with scripting around batch processes, test execution preparation, data extraction, file movement and report generation.
  • Maintain automation scripts with clear comments, version control discipline and basic operational documentation.
  • Work with senior engineers to ensure scripts are safe, repeatable and suitable for controlled enterprise environments.
  • Test Data, SQL and Data Validation
  • Assist with preparing and validating test data for Murex test scenarios.
  • Use SQL to query and validate data in Murex and related databases.
  • Support reconciliation of test results, expected outcomes and actual system behaviour.
  • Assist with identifying data mismatches, missing data, incorrect outputs and unexpected test results.
  • Document data validation steps so they can be repeated and automated where appropriate.
  • Defect Analysis and Troubleshooting
  • Perform first-level analysis of failed automated tests and manual test issues.
  • Review logs, test outputs, SQL results, files and automation reports to identify possible causes of failures.
  • Raise clear and well-documented defects with supporting evidence.
  • Work with Murex engineers, developers, business analysts and support teams to reproduce issues and validate fixes.
  • Support root cause analysis by providing test evidence, logs, data extracts and repeatable test scenarios.
  • Release, Regression and Continuous Improvement
  • Support regression testing for Murex releases, changes and environment updates.
  • Maintain and improve regression packs so that commonly repeated test scenarios can be executed reliably.
  • Identify opportunities to reduce manual effort through MxTest automation, scripting or process improvement.
  • Contribute to improving testing standards, automation practices and support documentation.
  • Support post-release validation and early-life monitoring for changes where required.
  • Documentation and Knowledge Sharing
  • Document test cases, automated test scripts, test data requirements, execution steps and expected outcomes.
  • Maintain simple runbooks and support notes for recurring testing and automation tasks.
  • Create clear documentation for Python/Bash scripts, including purpose, inputs, outputs, assumptions and usage notes.
  • Share lessons learnt from test execution, defects and automation improvements with the team.
  • Build Murex product, testing and automation knowledge through on-the-job learning and guidance from senior engineers.

  • Basic SQL skills for querying, validating and comparing data.

  • Ability to understand structured data formats such as XML, CSV, JSON or similar.
  • Strong analytical and problem-solving ability.

  • Good written and verbal communication skills.
  • Ability to work under guidance from senior engineers, test leads or platform specialists.
  • Willingness to learn Murex MX.3, MxTest, capital markets processes and enterprise testing practices.
