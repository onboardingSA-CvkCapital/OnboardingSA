About the role

One of South Africa's leading diversified financial services groups, specializing in direct marketing and sales of financial products is seeking a Server Engineer to take end-to-end ownership of core server infrastructure, messaging, identity, virtualization, storage, and Microsoft cloud services. Responsibilities: • Windows Server Lifecycle: Administer, patch, harden, and troubleshoot Windows Server environments across Production, UAT, Dev, and DR. • VMware vSphere: Maintain ESXi hosts, vCenter, clusters, and datastores. Troubleshoot performance (CPU/memory pressure, storage latency, and network config). • Storage & SAN: Manage SAN-attached storage from a virtualization perspective, including capacity planning, LUN connectivity, and multipathing. • On-Premises AD: Support AD Domain Services, Group Policies (GPOs), Kerberos/LDAP authentication, replication health, and domain controller maintenance. • Hybrid Identity: Administer Microsoft Entra ID (Azure AD) and manage hybrid identity synchronization via Entra Connect. • Access Governance: Enforce least-privilege access, manage privileged accounts, and assist with audit readiness. • Exchange Hybrid: Maintain on-premises Exchange and Exchange Online coexistence, managing mailboxes, transport rules, connectors, and migration activities. • Mailflow Troubleshooting: Investigate complex mail delivery, relay, and certificate issues. • Email Security: Administer MailMarshal (or similar secure email gateways) and enforce robust sender authentication protocols (SPF, DKIM, DMARC). • M365 Administration: Support core M365 services (Teams, SharePoint, OneDrive) and handle licensing, compliance, and tenant health. • Azure Infrastructure: Support hybrid Azure resources including VMs, virtual networks, Network Security Groups (NSGs), and private endpoints. • Joint Investigations: Work with developers to isolate issues across IIS, SQL Server connections, scheduled tasks, certificates, and API/network dependencies. • Root Cause Analysis: Analyze event logs, message tracks, and performance counters to resolve application-infrastructure bottlenecks. • Proactive Monitoring: Maintain and improve alert monitoring dashboards (Nagios, PRTG, SolarWinds, or Azure Monitor). • Disaster Recovery (DR): Execute DR replication, backup testing (Veeam/enterprise tools), and failover validation. • Governance: Strictly adhere to change control, vulnerability remediation, and documentation standards. Minimum Requirements: • Experience: 7+ years of enterprise server/infrastructure engineering experience. • Core Systems: Deep expertise in Windows Server, Active Directory, Group Policy, DNS, and VMware vSphere. • Messaging: Expert-level knowledge of Exchange (on-premises & Online), mailflow, and email routing. • Email Security: Hands-on experience with secure email gateways (e.g., MailMarshal) and SPF/DKIM/DMARC configurations. • Escalation Focus: Proven track record of owning major production incidents and collaborating with developer teams. • Preferred Certifications • Microsoft Certified: Windows Server Hybrid Administrator Associate • Microsoft Certified: Azure Administrator Associate • Microsoft Certified: Messaging Administrator Associate (or equivalent Exchange experience) • VMware Certified Professional (VCP) • ITIL Foundation • Security certifications (e.g., Security+, SC-300, SC-200) • Nice-to-Haves • Experience in financial services, insurance, or highly regulated environments. • Hands-on experience with Azure infrastructure, Entra ID Connect, and PowerShell automation. • Familiarity with Linux administration (SSH, DNS, package management, basic scripting). • Database infrastructure support (SQL Server) and IIS web server administration. • Experience with Veeam or similar enterprise backup solutions. Benefits: Competitive salary based on experience (salary can potentially be more based on experience/skills) IF you meet the above requirements and want to make a career-changing move, apply today by emailing your CV to itcareers@hireresolve.za.com
