The Department of Roads and Transport (Gauteng) is hiring an Admin Officer: Security Services in Corporate Services, based in Bedfordview. This is a permanent post, paying R338,106 a year. Responsibilities

  • Monitor the physical security services: Monitor and ensure security service providers provide the required physical security services.
  • Monitor parking of vehicles in the premises in consultation with Core Business Units, Compile and communicate Security Instructions to Security as directed by the Unit Manager, Monitor the Lost and Found Storage in consultation with Unit Manager, Communicate Security instructions to Security Supervisor as Directed by the Unit Manager, monitor compliance to the Security Access Control Procedures, Communicate and Facilitate Access to parking yards.
  • Process Auction and Extra Security: Compile RLS01 and BOQ for planned auction, Facilitate all requirements of extra Security for the monitoring of Auctions, Participate in the Auction Planning and Postmortem meetings and present, Facilitate Security verification of auctioned vehicles and compile report, Compile Procedures and Processes for auction with the appointed security, Facilitate Auction Parade briefings, Facilitate auction vehicle dispatch, Monitor extra Security and ensure compliance with all requirements, Compile Security Auction Postmortem report and present findings.
  • Process Security Breach Incidents: Receive Security Breach Incident Reports from Security Service Providers, g-FleeT Officials and Visitors.
  • Open Security Breach Incident Files and Compile all required information, Update Security Breach Incident Register and Weekly/Monthly Reports, conduct preliminary investigations for all reported Security Breach Incident and escalate to Risk as directed by Manager, maintain all records of Security Breach Incident reported, Monitor Physical and Security Surveillance Helpdesk: Implement and Monitor Security Helpdesk as per Standard Operating Procedures.
  • Monitor Service Providers providing maintenance and ensure that all requirements are met, Compile communications on security matters as directed by the Unit Manager, Exercise strict confidentiality in and around security surveillance matters, Monitor Security improvement projects.
  • Comply with Risk processes and Mitigation: Comply to all relevant security Acts, Policies, Regulation and Standards, Monitor and enforce compliance to Security Policy, Plan, Processes and Procedures, Compile and submit weekly/monthly/quarterly security reports, maintain strict confidentiality on reported incidents Maintain the lost and found, keep record of incoming, stored and claimed (outgoing) lost and found items.
  • Plan, Reporting, Administration: Conduct Secretariat Services for security meetings and maintain strict confidentiality on all security discussions and resolutions, maintain filing system for all security documentation (manual and electronic), Verify all submitted security invoices compile analysis, compile snag lists, completion letters, and submit for approval.
  • Human resources: Supervise security Officials within the Section.

Requirements

  • A minimum 3 year National Diploma (NQF Level 6) in Security Management/Security Risk Management.
  • PSIRA Grade B.
  • At least 2-3 years’ experience in Security Management environment in the Public Service.
  • Knowledge
  • Minimum Information Security Standard (MISS) policy document
  • Information Security
  • Knowledge and understanding of Security Management
  • People oriented
  • Driver’s License will be an added advantage
