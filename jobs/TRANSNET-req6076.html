About the role

Transnet (Transnet Freight Rail) is hiring an Engineer, based in Braamfontein. The role reports to the Specialist: Traction & Locomotive Integr. Grade: F. To provide the Senior Engineer (Traction and Locomotive Integration Technology Technology) with engineering expertise in support of Locomotive Data Systems (Specification, front and back-end software Development, and maintenance of locomotive data systems) so that Transnet can provide a sustainable, safe, predictable and affordable transport service to its clients.

Responsibilities

  • Develop a comprehensive locomotive data systems strategy, inclusive of:
  • Locomotive data transmission protocol design and specification
  • Migration of the Locomotive Data System Architecture to a Microservices architecture
  • Continuous monitoring and technical support on all data collection devices
  • Optimising server configurations, resource utilisation and system parameters to maximise performance.
  • Software development, to support the following functions
  • Continuous data driven locomotive condition monitoring by various component VITs
  • Development of techniques and algorithms for the purpose of assisting Transnet with predictive maintenance
  • Develop Back-office locomotive data system software (Database management, back-end software, Data visualisation dashboards (front end), continuous locomotive condition monitoring, locomotive energy management system, Critical locomotive fault alerts messages)
  • Analyse and understand existing codebase, including its architecture, dependencies, and functionality.
  • Design, acceptance, and Continuous Condition Monitoring of data transmission devices:
  • To develop locomotive specification in line with technological advancements in the railway industry.
  • Perform failure analysis and investigations on components/ equipment and systems associated with Locomotive Data Systems and Performance.
  • Perform fault data analysis: Pinpoint potential problem areas to conduct technical investigations and to propose solutions
  • Data Governance, Data Security and Cyber Security
  • Ensure compliance to Data Governance and Data Security
  • Ensure OT cyber security road map is implemented and continuous improvements to LDS cyber security.
  • Data Mining to enable Big data analytics insight and extraction
  • Data frames
  • Time series analytics to deduce the seasonality and stationarity in relation to the some of the failures on the locomotives
  • To oversee and maintain version control systems (like GIT) ensuring efficient collaboration and code management. Responsibilities include:
  • Managing repositories
  • DevOps and setting up CI/CD pipelines.

  • 5. Experience with design, application, testing and configurations of TCP/IP or UDP/IP Data Communication protocols
