About the role

The Department of E-Government (Gauteng) is hiring 2 Shift Leader - Security posts in Security Management, based in Johannesburg. This is a permanent post, paying R201,093 a year. How to apply: To apply for the below positions, please submit your application strictly online at http://professionaljobcentre.gpg.gov.za. No hand-delivery or emailed applications will be accepted. Reference number to quote: REFS/057304 Closing date: 27 November 2026 Use the new Z83 form and attach a detailed CV.

Responsibilities

  • Performs the administrative duties for all security related functions associated with an assigned shift.
  • Drafting duty rosters and posting sheets, Monitor the proper posting and deploying of security personnel daily.
  • Allocate security tasks.
  • Monitor attendance of security officers.
  • Conduct uniform/dress code inspection.
  • Implement parade during booking on duty.
  • Enforce adherence to site instructions and procedures.
  • Liaise with Senior Security Officer in terms of daily operations.
  • Conduct hand over to the next shift.
  • Implement the security operational plan.
  • Assist with the control of emergency plan and evacuation procedures and drills.
  • Assist with the planning of security measures for events.
  • Monitor and provide support in case of emergencies.
  • Administer all controls room operations to safeguard the department assets.
  • Supervise all control rooms activities.
  • Report all incidents and any identified non- compliance relating to security prescripts.
  • Review of footage upon request through proper procedure.
  • Update all registers for the incidents observed.
  • Monitor incidents/occurrence books/registers.
  • Monitor access control to prevent unauthorised entry in buildings and other premises.
  • Authorise the equipment, documents, and stores into or out of the building or premise.
  • Inspect the functioning of electronic, radio and panic button systems.
  • X- Ray machines, walk - through metal detectors, security lights and report all none functioning of security measures.
  • Record security incidents and breaches and report to the Senior Security Officer.
  • Control the keeping of registers as needed and the recording of all security related activities and incidents.
  • Identify risk and thread to the security of the department.
  • Assist with the investigation of security incidents and breaches and provide input on preventative measures.
  • Compile reports to Senior Security Officers as needed.

Requirements

  • Grade 12 Certificate at NQF level 4 as recognized by SAQA with Grade C Security Training registered with PSIRA.
  • 3 Years security experience in a supervisory level.
