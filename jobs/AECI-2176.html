About the role

AECI is hiring a Test Development Engineer, based in Modderfontein. Purpose of the job: Responsible for manual and automated testing of engineering software to ensure functionality, reliability and quality before release. The incumbent will develop automated tests using Playwright and requires strong C, Golang and Python programming knowledge.

Responsibilities

  • Develop and execute manual test cases based on software requirements.
  • Perform functional, regression, integration and exploratory testing.
  • Identify, document and verify software defects.
  • Design, develop and maintain automated tests using Playwright.
  • Convert suitable manual tests into automated regression tests.
  • Analyse test failures and support root-cause investigation.
  • Develop test utilities and scripts using C and other relevant languages.
  • Review requirements and contribute to test planning and test coverage.
  • Work closely with Software Development, Engineering and Quality teams.
  • Maintain test documentation and provide software quality feedback.
  • Identify opportunities to improve testing efficiency through automation.

Requirements

  • Requirements: Qualifications and Experience
  • Degree in Software Engineering, Computer Science, Computer Engineering, Electrical/Electronic Engineering or related field.
  • 1 to 3 years' experience in software testing, test development or automation.
  • Practical experience with manual software testing.
  • Some knowledge with Playwright or a similar automation framework.
  • Strong knowledge of C programming.
  • Some knowledge of Golang programming
  • Experience with software debugging and troubleshooting
  • Knowledge of Git/version control
  • Understanding of software development and testing lifecycles.
  • Personal Attributes
  • Strong analytical and logical thinking skills.
  • Attention to detail and commitment to quality.
  • Good verbal and written communication skills.
  • Strong interpersonal and teamwork skills.
  • Self-motivated with a willingness to learn and develop.
  • Ability to manage tasks and meet deadlines.
  • High regard for safety, compliance, and professional ethics.
